# TaskFlow - Task Management System

TaskFlow is a full-stack Task Management System developed
using React.js, Tailwind CSS, Node.js, and Express.js.

The application allows users to organize tasks, manage
projects, track task status, and view notifications.

## Features

- Home Dashboard
- User Login and Logout (Frontend Demo)
- Create Tasks
- View Tasks
- Search Tasks
- Filter Tasks by Status
- Mark Tasks as Completed
- Delete Tasks
- Project Management Interface
- Notifications Interface
- Responsive Navigation
- React Hooks and Context API
- RESTful APIs
- Backend API Testing using Postman

## Installation

### Clone the Repository

git clone https://github.com/YOUR-USERNAME/task-management-system.git

### Install Frontend Dependencies

cd task-management-system/client
npm install

### Run Frontend

npm run dev

### Install Backend Dependencies

Open another terminal.

cd task-management-system/server
npm install

### Run Backend

npm run dev

## API Endpoints

GET    /api/tasks

GET    /api/tasks/:id

POST   /api/tasks

PUT    /api/tasks/:id

DELETE /api/tasks/:id

## Project Description

This project demonstrates the integration of a React
frontend with an Express backend using RESTful APIs.

It uses React Hooks, Context API, reusable components,
routing, and asynchronous API requests.

The current backend uses in-memory task data for
demonstration purposes.
